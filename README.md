# Ударник

Мобильное приложение-тренажёр ударений для **задания 4 ЕГЭ по русскому языку**. Интерфейс как у Lingua Mini: карточки, квиз, прогресс, словарь.

## Что внутри

- **Весь орфоэпический словник ФИПИ** (существительные, прилагательные, глаголы, причастия, деепричастия, наречия) со всеми формами: зАнял — занялА — зАняли и т. д.
- Раздел **«Сверх словника»** — частые слова из сборников и пробников (ходАтайство, обеспЕчение, балОвать…).
- **Карточки**: слово без ударения → переворот → правильное ударение, пометка и подсказка-мнемоника.
- **Квиз «Где ударение?»**: нажимаешь на ударную гласную прямо в слове.
- **Формат ЕГЭ**: 5 слов, выбери все варианты с верным ударением (от 2 до 4), балл — только за полный правильный ответ.
- **Ошибки** собираются в отдельный список, по ним можно тренироваться.
- **Словарь**: поиск, скрытие выученных слов, добавление своих слов (звонИт — ударная гласная заглавной).
- Прогресс, серия дней, резервная копия.

## Локальный запуск

Понадобятся Node.js 20+ и npm.

```bash
npm ci
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Как получить APK через GitHub — пошагово

### 1. Создай репозиторий

1. Войди на [github.com](https://github.com).
2. Нажми **New repository**.
3. Назови его, например `udarnik`.
4. Выбери **Private** или **Public**.
5. Не добавляй README/.gitignore при создании — они уже есть в проекте.

### 2. Загрузи проект

В терминале, открытом в папке проекта:

```bash
git init
git add .
git commit -m "Udarnik Android app"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/udarnik.git
git push -u origin main
```

Вместо `ТВОЙ_ЛОГИН` укажи имя аккаунта GitHub. Если Git попросит авторизацию, используй вход через браузер или Personal Access Token вместо пароля.

### 3. Запусти workflow

Workflow уже лежит в `.github/workflows/android.yml`.

1. Открой репозиторий на GitHub.
2. Перейди во вкладку **Actions**.
3. Слева выбери **Android APK**.
4. Нажми **Run workflow** → **Run workflow**.
5. Подожди, пока запуск станет зелёным. Обычно это занимает несколько минут.

Workflow автоматически:

1. устанавливает Node.js 24 и Java 17;
2. выполняет `npm ci`;
3. проверяет TypeScript и собирает Vite-приложение;
4. создаёт/синхронизирует Android-проект Capacitor;
5. запускает Gradle;
6. сохраняет APK и SHA-256 checksum.

### 4. Скачай APK

1. Открой завершённый запуск в **Actions**.
2. Пролистай до раздела **Artifacts**.
3. Скачай `udarnik-debug-apk`.
4. Распакуй ZIP — внутри будет `udarnik-debug.apk`.
5. Передай APK на Android-телефон, открой файл и разреши установку из неизвестного источника, если Android попросит.

> Это debug APK для личного использования и тестирования. Android может показать предупреждение, потому что приложение не опубликовано в Google Play.

## Автоматический GitHub Release

При отправке тега вида `v1.0.0` workflow создаст Release и прикрепит APK:

```bash
git tag v1.0.0
git push origin v1.0.0
```

После успешной сборки открой справа раздел **Releases**. Файлы:

- `udarnik-debug.apk`;
- `udarnik-debug.apk.sha256`.

## Если сборка упала

- **`npm ci`**: проверь, что `package-lock.json` добавлен в репозиторий и соответствует `package.json`.
- **Java/Gradle**: workflow использует JDK 17, а кэш Gradle подключается только после создания папки `android`. Это важно: до `npx cap add android` Gradle-файлов ещё нет.
- **`cap sync android`**: проверь `webDir: "dist"` в `capacitor.config.ts` и успешность шага web build.
- **Белый экран в APK**: для маршрутов используется `HashRouter`, а Vite настроен с `base: "./"` — не заменяй их на абсолютные пути.
- **Скачать артефакт нельзя**: войди в GitHub-аккаунт, у которого есть доступ к репозиторию.

## Где хранятся данные

Прогресс и добавленные слова сохраняются в локальном хранилище приложения на телефоне. При удалении приложения Android может удалить эти данные. Перед переустановкой экспортируй прогресс в настройках и свои слова на экране «Мой словарь».
